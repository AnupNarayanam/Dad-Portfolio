# Image slots

Drop a file with the exact name below into the matching folder. The site detects it automatically and replaces the placeholder. No code changes needed.

Accepted formats: `.jpg`, `.jpeg`, `.png`, `.webp` (use the base name only, for example `chapter-01.jpg`).

## Tips

- Keep each image under 500 KB. Export as JPG at around 80% quality, or WebP.
- Use real photographs only. Names and captions should be confirmed with the people shown.
